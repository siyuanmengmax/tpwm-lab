- `npm run build` 与 `npm run check` 通过。检查覆盖 52 处页面引用、双语路由、唯一 ID、标题结构、源文件和离线预览内嵌脚本语法、真实人员数量、论文状态及资源相对路径。

- 本地服务器页面与资源返回 200，目录地址补充斜线；缺失地址返回双语 404 页面；HEAD、非 GET 方法及无效编码 URL 的响应已验证。
- 使用临时 `SITE_URL=https://example.org/tpwm-lab` 构建，确认 canonical、hreflang、Open Graph URL 和 sitemap 支持仓库子路径；测试后已恢复无目标域名的本地构建。

中文字体栈与个人主页 `assets/css/chinese-typography.css` 一致。Chrome 通过字体检查确认主标题实际渲染为 `PingFangSC-Semibold`；320/390/768/1440px 布局无水平溢出，320/390px 下导航保持一行、首屏标题保持两行。离线预览切换中英文后应用对应字体；英文主标题仍为 Georgia。构建与既有静态检查通过。

## 样式缓存回归检查（2026-10-11）

构建器为 CSS 和 JavaScript 生成带内容哈希的文件名，并在双语 HTML 中引用对应资源；保留原始文件名以兼容此前缓存的页面。在独立浏览器中先加载旧版页面与长期缓存的旧 CSS，实际字体为 `Songti SC`；随后切换为新版 HTML、保留旧 CSS 地址及缓存，执行普通刷新，标题实际字体变为 `PingFang SC`。请求记录确认新版页面请求了新的 CSS 地址，未再次使用旧固定地址。手机布局与英文 Georgia 字体检查通过。

## 英文 Inter 字体（2026-10-11）

英文标题、正文、导航、论文和表单控件更换为自托管 Inter 4.1，包含正体与真实斜体；中文保留原有系统字体。Chrome 实际字体检查确认英文为 `Inter Variable`（正体和斜体均来自自定义字体文件），中文主标题仍为 `PingFang SC`，中文独立页面不请求 Inter 文件。

中英文分别在 320、390、768、1440px 宽度下无水平溢出。最窄英文页面的导航保持一行，研究流程改为单列以容纳较长单词。模拟断网后，单文件预览仍使用嵌入的 Inter，并能在中英文之间正确切换字体；无浏览器 JavaScript 异常。构建与静态检查通过，当前检查覆盖 53 处页面引用（新增英文正体字体预加载）。

## 导航栏图标（2026-10-11）

原导航图标由 `T` 和 `↗` 两个文字字符拼接，线上中英文分别继承 Inter 和 Georgia，截图确认形状不同。现改为内嵌 SVG，复用 `public/assets/favicon.svg`；字母与箭头均由路径绘制，不依赖字体。导航图标固定为 32 × 32px，禁止 flex 压缩，并由主页链接提供可访问名称。标签页图标采用同源 SVG 和内容哈希文件名。

Chrome 检查覆盖中英文各 320、390、768、1440px：导航图标尺寸和 SVG 内容一致，无水平溢出，窄屏导航保持一行，favicon 可正常加载。禁用 JavaScript、断网打开单文件预览和切换语言后图标均正常；无浏览器异常。构建、53 处引用检查和源文件检查通过。用户设备上的具体显示异常未单独复现。
